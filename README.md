# ImageCompare

Esta extensión añade una etiqueta que muestra un control deslizante interactivo para comparar dos imágenes una al lado de la otra. ‎<imgcomp>
esta es una version que fue corregida y adaptada al mediawiki moderno para las versiones mas recientes de mediawiki 1.45+ en adelante

instalacion

Descarga y mueve la ImageCompare carpeta extraída a tu extensions/directorio.
asegurate la carpeta de la extension se llame ImageCompare, Agrega el siguiente código en LocalSettings.php :
wfLoadExtension (  'ImageCompare'  );
